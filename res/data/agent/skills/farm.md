# 农场玩法

> 文中指令前缀以 `/` 为例，实际前缀由机器人配置决定。农场指令都是**独立顶层指令**（不是 `/农场.xxx` 分组），只有"铲除""天气预报订阅""一键操作"在 `农场.` 分组下。

## 田地与位置

- 每人的农场是一块 **D1-D8 × A-D 的格子田**（列为 A~D，行为 1~8），例如 `A1`、`C4`。
- 位置写法：单个位置直接写 `A1`；多个位置空格分隔 `A1 B2`；**矩形区域**用 `-` 连接对角 `A1-B3`。
- 位置字母大小写不敏感（内部会转大写）。
- 首次使用农场指令会自动创建农场数据。

## 指令列表

| 指令 | 别名 | 说明 |
|---|---|---|
| `/我的农场` | — | 以图片查看自己农场的全部田地状态 |
| `/播种 <位置> <种子名>` | `/种植` | 在指定位置播种 |
| `/锄地 <位置>` | `/耕地` | 锄地，是播种的前置条件 |
| `/浇水 <位置>` | — | 为田地浇水 |
| `/收获 <位置>` | — | 收获成熟作物 |
| `/施肥 <位置> <肥料名>` | — | 对指定位置使用肥料（消耗背包中的肥料） |
| `/农场.铲除 <位置>` | — | 移除田地里的作物 |
| `/农场.一键操作` | — | 自动对本人的田完成锄地、浇水与收获 |
| `/农场.天气预报订阅` | — | 订阅/取消本群农场的天气预报（管理员） |

- 播种与施肥的输入格式是 `位置 名字`，中间必须有空格，例如 `/播种 A1 胡萝卜`、`/施肥 A1-A3 基础肥料`。
- 输入不合法时会提示："1.位置是否正确 2.A1-B1 需要连在一起 3.是否含有种子名/肥料名"。
- 操作结果会按"位置 + 结果说明"分组回显，例如哪些格子成功了、哪些格子缺水。

## 操作前置条件

- **锄地**：播种前必须锄地；未锄地会拒绝播种。
- **浇水**：作物需要水分才能继续生长，缺水会停止生长。
- **收获**：只有完全成熟的作物才能收获。

## 品质与肥料

- 收获时按品质产出，共三档：**银 / 金 / 铱**，品质越高越稀有，对应背包里独立的物品。
- 品质由**耕种等级**与**地力（quality）**共同决定：掷点会随等级提升，而肥料可以直接提高地力。
- 肥料分两类效果：**提高品质**（直接抬高地力）与**提高生长速度**（缩短成熟时间）。
- 肥料是消耗品，必须先通过商店购买进入背包，`/施肥` 时会扣除一个。

## 耕种等级

- 耕种经验来自农事操作，等级按 `(等级+1)*1000` 递增需要经验。
- **等级越高，收获时越容易拿到高品质作物**，因此长期经营农场是有收益的。

## 天气

- 农场有天气系统，影响浇水与生长；可以订阅本群天气预报，每天自动推送。
