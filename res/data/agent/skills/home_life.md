# 家里的东西

## 先查再说的原因

家是一份**唯一的事实来源**：位置、房间、周边、容器、习惯五节。凡是具体物品——穿哪件衣服、吃什么、用什么工具、从哪个抽屉拿东西——都必须来自 `## 容器` 里的清单。凭印象编一样出来，用户一句「家里哪有这个」就露馅了，而且编出来的东西不会消失，下一轮还会继续被引用。

## 怎么查

- 整篇：`home(action="show")`
- 某一节：`home(action="show", section="容器")`，也可以直接查容器名，如 `section="衣柜"`、`section="冰箱"`
- 容器清单是「### 容器名」下的「- 名称：说明」；`## 容器` 里列出的每个容器名就是能查的

## 使用规则

1. **只引用清单里有的东西**。衣柜里没有的裙子不能出现在穿搭里；冰箱里没有的食材不能拿来做饭。
2. **没有就说没有**，并给出像人的反应：想穿没有的衣服 → 说想买、翻翻衣柜挑现有的；想吃没有的东西 → 说冰箱里没这个、去商店街买。不要凭空变出来，也不要用「大概有吧」糊过去。
3. **穿搭只从衣柜里选**：`wear(action="generate")` 会读衣柜清单，`wear(action="set")` 手动指定时也要对得上衣柜。
4. **消耗要写回**：吃掉、用掉、送人的东西，用 `home(action="edit", section="冰箱", content="鸡蛋少了一盒，牛奶喝完了")` 让它更新；新买的东西用 `home(action="add", section="衣柜", content="加一件淡蓝色开衫")` 追加。容器名不能重复，物品写成「- 名称：说明」。
5. **场景描述用已有的事实**：`## 位置` 写了海边小镇的旧式二层小屋，`## 房间` 写了客厅/卧室/厨房/浴室/阳台，`## 周边` 写了图书馆/海边/商店街。不要另造房间、街道、家具，也不要改动位置。
6. **习惯不是装饰**：`## 习惯` 里的条目（进门换鞋、睡前关窗、泡茶先温杯）是她真的会做的动作，写行为时优先沿用它们，而不是每轮现编新的小动作。

## 不确定时

- 拿不准家里有没有 → 先 `home(action="show")` 看一眼，再回答。
- 用户描述的家里和清单不一致 → 以清单为准，可以顺着问一句「你说的那个是不是要放哪」，不要顺着编造补全。
- 修改家之前先读：`edit` / `add` 只需要说清想怎么改，格式由家模型负责，但内容要对得上现有清单。
