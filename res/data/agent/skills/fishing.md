# 钓鱼玩法

> 文中指令前缀以 `/` 为例，实际前缀由机器人配置决定。其中 `/钓鱼.xxx` 是「钓鱼」服务下的**分组指令**，`/钓鱼`、`/收线` 是独立顶层指令。钓鱼是一个**两步操作**的玩法，必须两人配合节奏。

## 核心流程

1. `/钓鱼`（别名 `/抛钩`）：抛出鱼钩。会先提示"🎣中...请等待🐟上钩..."，等待时长由鱼饵、鱼竿、鱼具共同决定（10~30 秒减去装备加成，最快 1 秒）。
2. 上钩后机器人会喊 **"!!!🐟上钩了,快输入[/收线]!!!"**，此时必须在限定时间内输入 `/收线`（别名 `/收杆`）。
3. 收线成功后按鱼的**品质、长度**结算并入库，同时给出长度与介绍；如果一次钓到多条内容过长，会改用图片发送。

**常见失败原因**：

- 没抛钩就收线 → 提示"你还没有开始钓鱼"。
- 反应太慢，鱼跑了 → 收线失败，本次作废。
- 所在位置不能钓 → 需要先 `/钓鱼.前往 湖` / `/钓鱼.前往 河` / `/钓鱼.前往 海`。
- 体力不足 → 抛钩消耗 40 点体力（与农场共用体力条）。

## 地点 / 时间 / 季节 / 天气

- **地点**（内部键）：`river` 河、`lake` 湖、`ocean` 海。不同鱼只在特定地点出现。
- 每种鱼有自己的**出现时间区间**（例如河豚 12:00–16:00）、**季节**（spring/summer/fall/winter）与**天气**（sun 晴天 / rain 雨天）。
- 条件不满足时钓不到该鱼，只会钓到垃圾和其他杂物（如垃圾、浮木、绿藻）。**"为什么总钓到垃圾"通常就是地点/时间/季节/天气不对。**

## 装备系统

三类装备，每类各装一件：

| 类型 | 代表物品 | 效果 |
|---|---|---|
| 鱼竿 | 木钓竿 → 铜钓竿 → 铁钓竿 → 金钓竿 → 铱钓竿 | 提升**品质**、减少**咬钩时间**，品级越高耐久越多 |
| 鱼饵 | 初级鱼饵 → 中级鱼饵 → 高级鱼饵 | 提升**咬钩速度**与**品质**，消耗品 |
| 鱼具 | 基础鱼钩、皮革浮标、钢制铅坠等 | 综合加成：等待时间、品质、反应时间、宝藏概率、额外钓上鱼的概率 |

- 装备有**耐久**，使用会磨损；耐久耗尽需要更换。
- 装备可通过**渔具商店**购买（渔具商店售卖各种渔具）。
- 鱼竿/鱼饵/鱼具的名称是配置里的中文名，例如 `/钓鱼.装备 铁钓竿`、`/钓鱼.装备 高级鱼饵`。
- 不存在或不可装备的物品会提示"你没有装备 X 或者 X 不能装备"。

## 宝藏与成就

- 钓鱼有**宝藏掉落**：鱼具会提高宝藏概率，宝藏内容是鱼饵、鱼钩、浮标、铅坠等装备的补充（例如初级鱼饵 ×10）。
- 收线时若达成新成就会额外播报"XX 获得成就"。
- 成就分**已达成 / 未达成**两组展示，未达成的描述即为达成条件。

## 经验与等级

- 每条鱼与杂物都有对应的经验值（`xp`），越稀有、越难钓的鱼经验越高。
- 钓鱼信息页会展示经验与等级进度。
